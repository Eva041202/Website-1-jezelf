## Wat heb ik geleerd? 
Geleerd hoe je een dark en light theme kan maken in CSS (dit wil ik toepassen in mijn website) 
100% = erg verzadigd = velle kleuren. Hoe minder veel procent, hoe minder verzadigd, hoe grijzer. 
Hoe de kleur aan te passen en dat de Light-dark-mode nog steeds werkt. 

Hoe responsiveness werkt. Dit kan ik enigszins goed volgen, maar heeft meer oefening nodig. 

Zelf voor het eerst flexbox geprobeerd. Dit werkte, maar deed toch niet helemaal wat ik wilde.

Op die manier kon het kopje Minor grid-column-start:2 naar de rechterkant verplaatst worden. 
Dit heb ik genoteerd om niet te vergeten. Ik begrijp waarom dit mogelijk is met deze code. 

Sanne heeft me laten zien dat ik het stuk in de CSS van item en box, dat hetzelfde is, in één rij kon zetten met: .item,.box { 
Dit scheelt veel typwerk en ruimte.
